Universal Fleet Worker Onboarding & 1-Click Bootstrap

Turn any Raspberry Pi 5, Pi 4, Jetson Nano, or Windows PC into an autonomous 24/7 scraping node with automated dependency resolution & hardware auto-tuning.

⚡ Concurrency Auto-Tuning Included
⚡ Step 1: 1-Click Universal Bootstrap Command (Fresh or New Pi) Automates Everything

Open terminal on your Raspberry Pi and paste this single command. It clones the repo, installs all system/apt packages, sets up uv, downloads Playwright Chromium for ARM64, runs the thermal & concurrency benchmark, and launches the 24/7 background systemd daemon:

BASH TERMINAL (ONE-CLICK DEPLOY)
git clone https://github.com/MaheswaranPalaniselvan/udayam-source.git ~/udayam && cd ~/udayam && bash scripts/bootstrap_worker.sh
🔄 Already Have the Code Cloned on your Pi? (Quick Update & Launch)

If you already have ~/udayam on your Pi 5, pull the latest repo updates and run the bootstrap installer directly:

BASH TERMINAL (EXISTING WORKSPACE)
cd ~/udayam && git pull origin main && bash scripts/bootstrap_worker.sh
🎯 Step 2: Optimal Concurrency Benchmark & Active Cooler Test

Run the built-in benchmark script to test your Pi 5 with the Active Cooler. It stress-tests ONNX OCR inference across concurrency levels 1, 2, and 3, monitors temperature and fan RPM, and saves the optimal setting:

RUN HARDWARE AUTO-TUNER
cd ~/udayam && uv run python scripts/benchmark_concurrency.py --apply

Real-time Active Cooler thermal & fan speed monitor command:

WATCH TEMPERATURE & FAN RPM
watch -n 1 "vcgencmd measure_temp; vcgencmd get_throttled; cat /sys/devices/platform/cooling_fan/hwmon/*/fan1_input 2>/dev/null | awk '{print "Fan RPM: " \$1}'"
🛠️ Step 3: Managing the 24/7 Background Daemon

The worker runs continuously as a managed systemd service, automatically restarting after reboots or WiFi hiccups:

VIEW LIVE SCRAPING LOGS
journalctl -u udyam-worker -f
CHECK SERVICE HEALTH
sudo systemctl status udyam-worker
RESTART WORKER
sudo systemctl restart udyam-worker
⚡ NVIDIA Jetson Nano 1-Click Bootstrap Concurrency 1 Tuned

Jetson Nano shares 4GB total RAM between the CPU and Maxwell GPU. Concurrency is automatically constrained to 1 to guarantee zero swap-thrashing and steady 10-12 rpm extraction:

BASH TERMINAL (JETSON NANO)
git clone https://github.com/MaheswaranPalaniselvan/udayam-source.git ~/udayam && cd ~/udayam && bash scripts/bootstrap_worker.sh

Enable 5V PWM fan on Jetson heatsink:

ACTIVATE 5V PWM FAN
sudo sh -c 'echo 200 > /sys/devices/pwm-fan/target_pwm'
🪟 Windows 1-Click Quick Deploy

Run in PowerShell on any Windows 10/11 workstation or laptop. Sets up dependencies, Playwright Chromium, and desktop launcher shortcut:

POWERSHELL SETUP
git clone https://github.com/MaheswaranPalaniselvan/udayam-source.git; cd udayam; .\setup_machine.bat

Start Headless Fleet Worker with Auto-Concurrency (4 workers):

LAUNCH WINDOWS FLEET WORKER
uv run python client/app.py --cli --machine "Win-$env:COMPUTERNAME" --concurrency 4
☁️ Linux VPS / Google Colab / Dedicated Cloud Worker

Deploy on any Debian/Ubuntu cloud server, Docker container, or virtual machine:

BASH TERMINAL (CLOUD WORKER)
git clone https://github.com/MaheswaranPalaniselvan/udayam-source.git ~/udayam && cd ~/udayam && bash scripts/bootstrap_worker.sh
